# Kit Obsidian + Quartz para compañeros de trabajo de grado

[[notas/index|← Notas]] · Relacionado con [[marco-metodologico]]

## Objetivo del kit

Ayudar a compañeros de trabajo de grado de la Facultad de Comunicaciones a construir un espacio digital de investigación donde puedan organizar y comunicar su proceso académico usando **Obsidian + Quartz + GitHub Pages**, con apoyo crítico de inteligencia artificial generativa.

## Qué problema resuelve

Muchos estudiantes tienen avances, referencias, ideas, notas y borradores dispersos en Word, Google Docs, chats, PDFs o carpetas sueltas. Esto dificulta ver el proceso de investigación como un sistema organizado. Obsidian permite ordenar el pensamiento mediante notas enlazadas, mientras que Quartz permite publicar una versión navegable del proceso en la web.

## Estructura sugerida de carpetas

```text
content/
  index.md
  about.md
  investigacion.md
  estado-del-arte.md
  marco-teorico.md
  marco-metodologico.md
  avances/
    index.md
  notas/
    index.md
  referencias/
    index.md
```

## Páginas mínimas para cada compañero

### 1. Inicio

Debe presentar:

- nombre del estudiante;
- programa;
- tema de investigación;
- pregunta guía;
- estado del proceso;
- enlaces a las secciones principales.

### 2. Investigación

Debe incluir:

- tema;
- planteamiento del problema;
- justificación;
- pregunta;
- objetivo general;
- objetivos específicos;
- declaración de uso de IA, si aplica.

### 3. Estado del arte

Debe incluir:

- criterios de búsqueda;
- matriz de antecedentes;
- tendencias encontradas;
- vacíos de investigación;
- aportes al proyecto propio.

### 4. Marco metodológico

Debe incluir:

- enfoque;
- tipo de estudio;
- participantes o corpus;
- técnicas;
- instrumentos;
- categorías de análisis;
- consideraciones éticas.

### 5. Avances

Debe funcionar como bitácora del proceso:

- decisiones tomadas;
- reuniones con asesor;
- cambios de pregunta;
- hallazgos;
- dificultades;
- próximos pasos.

## Flujo de acompañamiento propuesto

### Taller 1: Organización del trabajo de grado en Obsidian

1. Crear estructura de carpetas.
2. Crear notas principales.
3. Enlazar notas con wikilinks.
4. Definir etiquetas.
5. Crear bitácora de avances.

### Taller 2: IA generativa para investigar y escribir

1. Crear prompts de exploración del tema.
2. Formular palabras clave.
3. Construir fichas de lectura.
4. Verificar fuentes.
5. Mejorar borradores sin perder autoría.
6. Declarar uso de IA.

### Taller 3: Publicación con Quartz y GitHub Pages

1. Preparar contenido público.
2. Separar notas privadas y notas publicables.
3. Configurar Quartz.
4. Subir repositorio a GitHub.
5. Activar GitHub Pages.
6. Revisar navegación y enlaces.

## Reglas éticas básicas

- No publicar datos personales sensibles.
- No subir entrevistas completas sin autorización.
- No publicar nombres de participantes sin consentimiento.
- No usar IA para inventar referencias.
- Declarar cuándo se usó IA en escritura, edición o análisis.
- Verificar toda cita, enlace o dato generado por IA.
- Publicar solo avances que el estudiante quiera hacer visibles.

## Entregable esperado por participante

Cada compañero podría terminar con:

- una bóveda organizada en Obsidian;
- una página de inicio;
- una página de investigación;
- una página de metodología;
- una página de estado del arte;
- una bitácora de avances;
- un sitio Quartz publicado o un prototipo local;
- una reflexión sobre el uso de IA y publicación digital en su proceso.

## Valor comunicativo

Este kit convierte el trabajo de grado en un proceso comunicable, no solo en un documento final. Permite analizar cómo los estudiantes organizan, narran, enlazan y publican conocimiento académico, y cómo la IA generativa interviene en la investigación, la escritura, la verificación y la circulación de información.
